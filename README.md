# Лендинг Андрея Снегурова — персональный фитнес-тренер

Одностраничный сайт по макету Figma. Вся конверсия ведёт в личную переписку с Андреем в Telegram.

## Что это технически

Три файла и папка с картинками. Ни сборки, ни зависимостей, ни node_modules — открываешь `index.html` в браузере, и он работает.

```
index.html    вся разметка: меню, hero, обо мне, мой подход, услуги, отзывы, контакты
styles.css    токены, компоненты, секции, три брейкпоинта
script.js     подсветка активного пункта меню, карусель отзывов, появление блоков
assets/       фотографии, иконка-стрелка, декоративная ломаная
favicon.svg   иконка вкладки
docs/         спека и план, по которым сайт собран
```

Порядок блоков в CSS и JS совпадает с порядком секций в HTML — искать нужное место стоит по комментариям-разделителям.

## Как посмотреть локально

Просто открыть `index.html` двойным щелчком тоже сработает, но правильнее поднять локальный сервер — тогда пути и шрифты ведут себя ровно как на боевом хостинге:

```bash
node .claude/dev-server.js
```

Затем открыть `http://localhost:5173`.

## Как поменять ссылки

Все ссылки на Telegram и Instagram — обычные `href` прямо в `index.html`, никакого JS: `https://t.me/Andrei_Jr18` в шести местах (все CTA и кнопка в контактах) и `https://www.instagram.com/snegurov.jr18/` в одном. Менять — поиском по файлу.

## Шрифты

Заголовки, кнопки и цифры — оригинальный `Electrolize [RUS by Daymarius]` из макета, файл лежит в `assets/fonts/electrolize-rus.ttf` и подключён через `@font-face` в начале `styles.css`. У него одно начертание, поэтому везде используется вес 400. Основной текст — `Montserrat Alternates` с Google Fonts.

Имя шрифта упоминается только в `@font-face` и в переменной `--font-display` — если понадобится заменить, менять нужно там и только там.

## Как поменять цвета и отступы

Всё в блоке `:root` в начале `styles.css`: `--bg`, `--accent`, `--text`, радиусы, ширина контейнера и поля для каждого брейкпоинта. В остальном файле цвета захардкожены только внутри inline-SVG (обводка цитаты в «Обо мне»).

## Как выложить

### GitHub Pages

1. Создать репозиторий и запушить туда содержимое этой папки.
2. Settings → Pages → Source: `Deploy from a branch`, ветка `main`, папка `/ (root)`.
3. Через минуту сайт будет на `https://<логин>.github.io/<репозиторий>`.

### Netlify

Перетащить папку проекта на [app.netlify.com/drop](https://app.netlify.com/drop). Ссылка выдаётся сразу.

### Vercel

Импортировать репозиторий на [vercel.com/new](https://vercel.com/new). Framework preset — `Other`, build command оставить пустым.

После выбора домена не забыть поправить `og:image` — см. `TODO.md`.

## Адаптивность

Вёрстка mobile-first, три состояния:

| Ширина | Что происходит |
|---|---|
| до 767px | точная копия макета: одна колонка, контейнер 390px |
| 768–1023px | контейнер 720px, «Мой подход» в две колонки, у карусели появляются стрелки |
| от 1024px | контейнер 1120px, hero в две колонки, услуги в три карточки в ряд |

## Что важно знать при правках

- **Свечения на фоне** — это `div.glow` с `filter: blur(129.6px)`. Позиция задаётся инлайн-переменными `--glow-x` / `--glow-y` / `--glow-size` в координатах макета 390px. Тем, что в макете прижаты к правому краю, добавлен класс `glow--right` — на широком экране они привязываются к правому краю, а не уезжают в середину.
- **Номера 01–04** намеренно выходят за левый край экрана, как в макете. Обрезка живёт в `overflow-x: clip` на `.section`. Если убрать это свойство, страница станет шире экрана и появится горизонтальная прокрутка.
- **Карусель отзывов** построена на нативном горизонтальном скролле со `scroll-snap`, а не на `transform`. Поэтому свайп родной, а сама карусель листается даже при выключенном JS. Скрипт добавляет только индикаторы, стрелки, клавиатуру и подгонку высоты под активный слайд.
- **Анимация появления блоков** включается классом `js-enabled`, который скрипт вешает на `<html>`. Без JS класса нет, начальная прозрачность не применяется, и весь контент виден сразу — страница не может «остаться пустой».
- **hero-фото** — вырезка с прозрачным фоном (`hero-andrew.png`). Если заменить её на снимок с непрозрачным фоном, за фигурой пропадут синяя ломаная и подсветка. Тень за фигурой — отдельный файл `hero-shadow.png`: чёрный силуэт той же вырезки, размытый и сдвинутый вправо-вниз CSS-ом. При замене фото силуэт нужно пересобрать из новой вырезки (это её альфа-канал, залитый чёрным).
- **Фотографии без скруглений.** Все JPEG в `assets/` — прямоугольные, скругление углов делает CSS. Экспорт из Figma со скруглением сюда класть нельзя: за пределами скругления он оставляет белые углы, и по краю CSS-скругления проступает белая кайма.

## Поддержка браузеров

Chrome, Firefox, Safari, Edge — последние две версии, плюс мобильные Safari и Chrome. Из современных возможностей используются `overflow: clip`, `aspect-ratio`, CSS-переменные и `IntersectionObserver`; в браузерах без `overflow: clip` срабатывает запасной `overflow-x: hidden` на корне.
